# PyCharm 快捷键 PyCharm Shortcuts

## 基础编辑 Basic Editing

### 代码生成 Code Generation
- `Alt + Insert` (Windows/Linux) / `Cmd + N` (Mac): 生成代码（构造函数、getter/setter等）
- `Ctrl + O` / `Cmd + O`: 重写方法
- `Ctrl + I` / `Cmd + I`: 实现方法

### 代码导航 Code Navigation
- `Ctrl + N` / `Cmd + O`: 查找类
- `Ctrl + Shift + N` / `Cmd + Shift + O`: 查找文件
- `Ctrl + B` / `Cmd + B`: 跳转到声明
- `Ctrl + Alt + B` / `Cmd + Option + B`: 跳转到实现
- `Ctrl + Shift + B` / `Cmd + Shift + B`: 跳转到类型声明
- `Ctrl + U` / `Cmd + U`: 跳转到父类方法

### 代码编辑 Code Editing
- `Ctrl + D` / `Cmd + D`: 复制行
- `Ctrl + Y` / `Cmd + Delete`: 删除行
- `Ctrl + Shift + Up/Down` / `Cmd + Shift + Up/Down`: 移动语句
- `Ctrl + /` / `Cmd + /`: 行注释
- `Ctrl + Shift + /` / `Cmd + Shift + /`: 块注释

### 重构 Refactoring
- `Shift + F6`: 重命名
- `Ctrl + Alt + M` / `Cmd + Option + M`: 提取方法
- `Ctrl + Alt + V` / `Cmd + Option + V`: 提取变量
- `Ctrl + Alt + C` / `Cmd + Option + C`: 提取常量
- `Ctrl + Alt + F` / `Cmd + Option + F`: 提取字段

## 高级功能 Advanced Features

### 搜索和替换 Search and Replace
- `Ctrl + F` / `Cmd + F`: 查找
- `Ctrl + R` / `Cmd + R`: 替换
- `Ctrl + Shift + F` / `Cmd + Shift + F`: 全局查找
- `Ctrl + Shift + R` / `Cmd + Shift + R`: 全局替换

### 运行和调试 Run and Debug
- `Shift + F10` / `Ctrl + R`: 运行
- `Shift + F9` / `Ctrl + D`: 调试
- `F8`: 单步执行
- `F7`: 单步进入
- `Shift + F8`: 单步跳出
- `F9`: 恢复程序

### 窗口管理 Window Management
- `Alt + 1` / `Cmd + 1`: 项目窗口
- `Alt + 7` / `Cmd + 7`: 结构窗口
- `Ctrl + E` / `Cmd + E`: 最近文件
- `Ctrl + Shift + E` / `Cmd + Shift + E`: 最近编辑位置

### 代码分析 Code Analysis
- `Ctrl + Alt + L` / `Cmd + Option + L`: 格式化代码
- `Ctrl + Alt + O` / `Cmd + Option + O`: 优化导入
- `Ctrl + F7` / `Cmd + F7`: 查找使用

## 技巧 Tips

### 多光标编辑
- `Alt + J` / `Ctrl + G`: 选中下一个相同的词
- `Alt + Shift + J` / `Ctrl + Shift + G`: 取消选中最后一个相同的词
- `Ctrl + Alt + Shift + J` / `Cmd + Ctrl + G`: 选中所有相同的词

### 快速修复
- `Alt + Enter` / `Option + Enter`: 显示意图操作和快速修复
