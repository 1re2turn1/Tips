# VS Code 快捷键 VS Code Shortcuts

## 常用编辑快捷键 Common Editing Shortcuts

### 多光标编辑 Multi-cursor Editing
- `Ctrl + D` (Windows/Linux) / `Cmd + D` (Mac): 选中下一个相同的词
- `Ctrl + Shift + L` / `Cmd + Shift + L`: 选中所有相同的词
- `Alt + Click` / `Option + Click`: 添加光标

### 代码导航 Code Navigation
- `Ctrl + P` / `Cmd + P`: 快速打开文件
- `Ctrl + Shift + O` / `Cmd + Shift + O`: 跳转到符号
- `F12`: 跳转到定义
- `Alt + F12` / `Option + F12`: 查看定义（预览窗口）
- `Shift + F12`: 查找所有引用

### 代码编辑 Code Editing
- `Ctrl + /` / `Cmd + /`: 切换行注释
- `Shift + Alt + A` / `Shift + Option + A`: 切换块注释
- `Alt + Up/Down` / `Option + Up/Down`: 移动行
- `Shift + Alt + Up/Down` / `Shift + Option + Up/Down`: 复制行
- `Ctrl + Shift + K` / `Cmd + Shift + K`: 删除行

### 搜索和替换 Search and Replace
- `Ctrl + F` / `Cmd + F`: 查找
- `Ctrl + H` / `Cmd + H`: 替换
- `Ctrl + Shift + F` / `Cmd + Shift + F`: 全局搜索
- `Ctrl + Shift + H` / `Cmd + Shift + H`: 全局替换

### 面板和窗口 Panels and Windows
- `Ctrl + B` / `Cmd + B`: 切换侧边栏
- `` Ctrl + ` `` / `` Cmd + ` ``: 切换终端
- `Ctrl + Shift + E` / `Cmd + Shift + E`: 显示资源管理器
- `Ctrl + Shift + G` / `Cmd + Shift + G`: 显示源代码管理

## 高级技巧 Advanced Tips

### Zen 模式
- `Ctrl + K Z` / `Cmd + K Z`: 进入专注模式（Zen Mode）

### 重构
- `F2`: 重命名符号
- `Ctrl + Shift + R` / `Cmd + Shift + R`: 重构

### IntelliSense
- `Ctrl + Space` / `Cmd + Space`: 触发建议
- `Ctrl + Shift + Space` / `Cmd + Shift + Space`: 触发参数提示

## 自定义快捷键 Custom Shortcuts

可以通过 `File > Preferences > Keyboard Shortcuts` 或 `Code > Preferences > Keyboard Shortcuts` 自定义快捷键。
